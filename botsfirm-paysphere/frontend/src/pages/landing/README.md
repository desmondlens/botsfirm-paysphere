# pages/landing/

Public, unauthenticated marketing surface. No login required.

## Pages

- **LandingPage** — hero, value props, social proof, call-to-action.
- **PricingPage** — plan tiers and pricing in BWP. Highlights free 7-day trial.
- **DemoCalculator** — interactive Botswana PAYE calculator. Lets visitors type a gross salary and see net pay, PAYE, and SDL using the 2025/2026 brackets. Acts as a lead magnet.
- **FeaturesPage** — feature breakdown by role.
- **ContactPage** — support email + form.
- **LegalPages** — Terms of Service, Privacy Policy.

## Conventions

- All pages must work without an auth session.
- SEO-friendly: meta tags, descriptive titles, semantic HTML.
- The demo calculator runs entirely client-side using shared tax bracket constants.
